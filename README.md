# homelab

A three-node Kubernetes cluster on mini PCs, built and run entirely from code.

**3** Proxmox hosts · **3** k3s nodes · **~30** namespaces · **~140** pods · **29** secrets from Vault ·
**24** network policies · **1** sign-in for all of it

## What's inside

Everything that runs here, including the parts whose config lives in private repos. The
diagrams are generated by [`docs/diagrams.py`](docs/diagrams.py).

### The cluster

Three VMs, one per Proxmox host, each a k3s server and a worker. The platform layer is
installed by Ansible; every app above it is a folder in git that Argo CD keeps in sync.

  <source media="(prefers-color-scheme: dark)" srcset="docs/cluster-dark.svg">

### Network and firewall

Nothing is open to the internet except the WireGuard endpoint and Plex. Devices come in over
WireGuard, and OPNsense decides per group what they can reach: my devices get everything,
family devices get HTTPS and DNS only. HAProxy on OPNsense puts one address in front of all
three nodes, so a node can go down without anything noticing.

### Secrets

Vault runs on its own VM, outside the cluster: the cluster can be rebuilt without losing a
secret, and a broken cluster can't lock me out of Vault. Apps get their secrets through
External Secrets; Ansible and Terraform look them up when they run.

## How it works

- **Git is the only way in.** A push to Forgejo (self-hosted, in the cluster) is picked up
  by Argo CD. GitHub gets a mirror.
- **Secrets never touch git.** They live in Vault, outside the cluster.
- **Updates are pull requests.** Renovate opens one per new image version; a workflow
  copies the image into the local registry before the merge, and nodes pull from there
  first.
- **One sign-in.** Authelia with 2FA guards every UI and `kubectl` itself (OpenID Connect).
- **Locked down inside too.** Network policies decide which pods may talk to which.
- **Hardware transcoding.** Each node's Intel iGPU is passed through to its VM and offered
  to Kubernetes; Plex asks for one.
- **Backups at every layer.** Volumes nightly to the NAS, Vault snapshots, whole-VM
  backups, ZFS replication between hosts.
- **Alerts that reach a phone.** Alertmanager pushes to ntfy and email, and an outside
  heartbeat notices if the cluster goes quiet.

## Rules it follows

- **Preview every change.** `terraform plan` and `ansible-playbook --check --diff` first;
  refactors are done when they show no changes.
- **Nothing depends on what it fixes.** Argo CD, the git server, sign-in and the admin UI
  are installed by Ansible, not by Argo CD. Vault runs outside the cluster.
- **Restarts are rolling and deliberate.** k3s config changes restart one node at a time,
  checking etcd in between. Vault is never restarted by automation, since that seals it.

## Hardware

Three Intel N100/N150 mini PCs running a Proxmox VE 9 cluster, a NAS for photos, media and
backups, and OPNsense as the firewall.
